# JARVIS Keybinds

Click the camera window first so it has focus, then use these keys.

## Servo head

| Key | What it does |
|---|---|
| `←` Left arrow | Turn the head left (hold to keep turning) |
| `→` Right arrow | Turn the head right (hold to keep turning) |
| `X` | Auto-follow on / off. Off = the head only moves with the arrow keys |
| `K` | Recalibrate the servo (direction and camera lag). Sit still for a second after pressing |
| `S` | Servo test wiggle |

While auto-follow is on, it pauses while you steer with the arrows and picks back up 4 seconds after your last press.

## Voice

| Key | What it does |
|---|---|
| `Space` | Mute / unmute the mic. If the call ended, wakes JARVIS back up |
| `A` | Cycle autonomy: off → aware → proactive |

## Camera and capture

| Key | What it does |
|---|---|
| `P` | Take a photo |
| `R` | Start / stop recording |
| `+` or `=` | Zoom in |
| `-` | Zoom out |
| `0` | Reset zoom to 1x |
| `↑` / `↓` Up / down arrows | Move the zoomed view up / down |
| `C` | Follow me: digital zoom keeps your face centered in the video |
| `G` | Hand gestures on / off |

## Window

| Key | What it does |
|---|---|
| `F` | Fullscreen on / off |
| `M` | Fit (whole image) / Fill (crop to fill the window) |
| `T` | Pin window on top / unpin |
| `Esc` | Quit JARVIS |

## Mouse

| Action | What it does |
|---|---|
| Scroll wheel | Zoom in / out toward the cursor |
| Left-drag | Move around the image while zoomed in |
| Right-drag a box | Track that object (the head follows it instead of your face) |
| Right-click | Stop tracking the object, go back to your face |
| Bottom button bar | − zoom, zoom level (click to reset), + zoom, Photo, Rec, Follow, Mic, Autonomy, Fit/Fill, Full |

## Hand gestures

Hold each one for about half a second. Open palm needs about a full second so talking with your hands doesn't trigger it.

| Gesture | What it does |
|---|---|
| 👍 Thumbs up | Photo after a 3-2-1 countdown |
| ✌️ Peace sign | Start / stop recording |
| ✋ Open palm | Mute / unmute the mic |
| 👎 Thumbs down | Reset zoom and stop object tracking |
